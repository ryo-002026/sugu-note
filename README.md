# SUGU

思いついたら、すぐ書ける。端末内にメモを保存する軽量PWAです。

## データについて
- メモはブラウザのIndexedDBに保存され、GitHubリポジトリには送信されません。
- PCとスマホの自動同期は未実装です。
- 既存の Mimi Sync JSON バックアップ（`mimi-sync-v1`）を読み込めます。
- ブラウザデータを消去するとメモが失われることがあるため、定期的にJSONバックアップを保存してください。
- 公開用ファイルに個人のメモやバックアップを含めないでください。

## 公開
GitHub Pages の main / (root) で公開できます。
